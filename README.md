## Часть 2. Описание собственного плагина «C-Buster»

### Назначение и идея проекта
**«C-Buster»** - это обучающий геймифицированный плагин-тренажёр и статический инспектор кода для студентов, изучающих язык программирования C и систему контроля версий Git. Плагин совмещает практические инструменты проверки качества кода (подсчет строк, контроль утечек памяти `malloc/free`, поиск глубокой вложенности условий и циклов) с интерактивной мини-игрой по поиску багов прямо в редакторе VS Code.

### Архитектура плагина
Проект построен по двухслойной модульной архитектуре:
1. **Аналитическое и игровое ядро на языке C (стандарт C23, компилятор LLVM Clang):**
   Состоит из 4 независимых консольных утилит в директории `c_core/`, которые принимают аргументы командной строки, выполняют посимвольный или построчный разбор файлов и выводят результат в стандартный поток вывода (`stdout`).
2. **Интеграционный слой VS Code (`package.json` и `extension.js`):**
   Регистрирует пользовательские команды в верхней панели редактора (`editor/title`), в контекстном меню (`editor/context`) и в нижней строке состояния (`StatusBarItem`). При действиях пользователя расширение вызывает скомпилированные бинарные файлы C через модуль `child_process.execFile`, перехватывает их текстовый вывод и отображает его в системных уведомлениях и выпадающих списках `QuickPick`.

### Структура файлов репозитория
```text
c-buster-plugin/
├── package.json         # Манифест расширения VS Code, регистрация команд и меню
├── extension.js         # Связующий модуль Node.js для вызова C-бинарников и обновления UI
├── README.md            # Документация проекта и отчёт о выполнении работы
├── .gitignore           # Исключение временных файлов и бинарных сборок из индекса Git
├── docs/screenshots/    # Архив скриншотов работы модулей, интерфейса и Kanban-доски
├── levels/              # Учебные файлы с намеренными ошибками для режима «Найди баг»
│   ├── bug_1.c          # Уровень 1: ошибка присваивания (= вместо ==) в условии if
│   ├── bug_2.c          # Уровень 2: пропуск оператора взятия адреса (&) в функции scanf
│   └── bug_3.c          # Уровень 3: выход за границы статического массива
└── c_core/              # Исходный код модулей ядра на языке C (стандарт C23)
    ├── analyzer.c       # Подсчет строк кода, комментариев, пустых строк и баланса malloc/free
    ├── detector.c       # Посимвольный анализатор глубины вложенности фигурных скобок { }
    ├── game_engine.c    # Игровой движок проверки строки с багом, подсчета очков и рангов
    └── quiz_bank.c      # Банк вопросов викторины по C23/Git и генератор профильных шуток
```

### Полный перечень реализованных функций
1. **Базовый функционал (Зеленый блок):**
   * Каркас расширения VS Code с автоматической проверкой и компиляцией C-модулей при запуске;
   * Кнопка приветствия `"C-Buster: Hello World"` и кнопка запуска уровня в верхней панели редактора (Toolbar);
   * 4 интерактивных пункта в контекстном меню редактора (вызов по правому клику мыши на любой строке кода);
   * Публичный репозиторий на GitHub с пошаговой историей коммитов в отдельных ветках.
2. **Полезные функции для разработчика (Желтый блок):**
   * **Статический подсчет строк и проверка памяти (`c_core/analyzer.c`):** считает общее количество строк, непустые строки с кодом, строки с однострочными и многострочными комментариями, пустые строки, а также сопоставляет количество вызовов `malloc(` и `free(`, предупреждая о возможных утечках динамической памяти;
   * **Детектор «Спагетти-кода» (`c_core/detector.c`):** отслеживает текущую и максимальную глубину вложенности блоков `{ }`, фиксирует номер строки с максимальным пиком и выводит предупреждение при превышении порога в 3 уровня вложенности;
   * **Таймер Кодера в строке состояния (Status Bar):** каждую секунду обновляет время активной работы программиста в IDE с возможностью сброса таймера по клику мыши;
   * **Генератор профильных шуток (`c_core/quiz_bank.c`):** выводит случайную шутку про язык C, указатели или работу с Git во всплывающем окне.
3. **Продвинутые игровые механики (Красный блок):**
   * **Обучающая игра «Найди баг в C» (`c_core/game_engine.c` + `levels/bug_1..3.c`):** игрок открывает учебный уровень через кнопку в Toolbar, изучает код, находит строку с ошибкой, кликает по ней правой кнопкой мыши и выбирает пункт `"C-Buster: Тут баг! (Проверить эту строку)"`. Движок сверяет номер строки под курсором, начисляет `+10 очков` при попадании и сохраняет прогресс в файл `score.txt`;
   * **Интерактивная викторина по C23 и Git (`c_core/quiz_bank.c`):** выводит вопрос с тремя вариантами ответа в меню `showQuickPick`, проверяет выбранный вариант и начисляет бонусные очки за правильный ответ;
   * **Система достижений и рангов (`c_core/game_engine.c`):** по мере накопления очков в статус-баре автоматически повышается игровой ранг студента: от *«Стажёр SimpleIT»* (0-10 очков) до *«Охотник за багами»* (20-30 очков) и *«Божество Указателей»* (40+ очков).

## Инструкция по сборке и запуску плагина

### Системные требования
* Установленный редактор **Visual Studio Code** (версия 1.75 и выше);
* Установленный компилятор **LLVM Clang** (`clang`) с поддержкой стандарта **C23**.

### Пошаговый запуск
1. Склонировать репозиторий и перейти в директорию проекта:
   ```bash
   git clone https://github.com/coffee-lay/c-buster-plugin.git
   cd c-buster-plugin
   ```
2. При необходимости скомпилировать модули ядра вручную через терминал (либо пропустить этот шаг - плагин автоматически скомпилирует их при активации):
   ```powershell
   clang -std=c23 -static c_core/analyzer.c -o c_core/analyzer.exe
   clang -std=c23 -static c_core/detector.c -o c_core/detector.exe
   clang -std=c23 -static c_core/game_engine.c -o c_core/game_engine.exe
   clang -std=c23 -static c_core/quiz_bank.c -o c_core/quiz_bank.exe
   ```
3. Открыть папку проекта в VS Code и нажать клавишу **`F5`** (или выбрать в верхнем меню `Run -> Start Debugging`).
4. В открывшемся тестовом окне **`[Extension Development Host]`** воспользоваться кнопками в правом верхнем углу редактора (Toolbar) или кликнуть правой кнопкой мыши внутри любого открытого файла `.c` для вызова функций **C-Buster**.

## Организация командной работы, Git и динамика Kanban-доски

Разработка велась в команде из 4 человек с использованием системы контроля версий Git и методологии Kanban в **GitHub Projects**:
* Каждый участник работал в собственной изолированной ветке (`feature/code-analyzer`, `feature/spaghetti-detector`, `feature/game-engine`, `feature/quiz-and-levels`, `feature/vscode-ui`);
* Слияние в основную ветку `main` производилось только через **Pull Requests** после перекрёстного **Code Review** другим участником команды;
* Вся работа была декомпозирована на 12 задач (Issues) с отслеживанием статусов (`Todo` -> `In Progress` -> `Code Review` -> `Done`).
